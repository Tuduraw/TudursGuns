# 検討: 投擲武器・地雷・関連装備・防具

状態: 方針決定済み。投擲物と弾薬箱は実装済み(未ビルド)。残りは末尾の「実装の順序」の順に作る。

## 基本方針

これまでの銃と同じ方針で作る。

- **データで定義する:** アイテムの種類はコードで固定し、個々の装備は JSON で定義する。
  - 投擲物・地雷・防具も、それぞれ1種類のアイテムにデータコンポーネントで「どの定義か」を持たせる。
  - 定義は `data/<ns>/throwable/`、`mine/`、`armor/`、`equipment/` に置き、アドオンフォルダにも対応する。
- **性能は武器ファイル(`.txt`)で書く:** 爆発・威力・信管・跳弾・弾のモデルは前提MODの武器ファイルで書き、`WeaponStatsLoader` で読む。
- **爆発は前提MODの弾体で起こす:** 手榴弾や地雷の爆発にも `VehicleProjectileEntity` を使う。
  - 車両のモデル形状に対する命中判定と、爆風による車両へのダメージがそのまま使える。
  - この爆風ダメージは前提MODの弾体でしか発生しない。独自の爆発では車両に正しくダメージが入らない。

## 1. 投擲武器(手榴弾など)

### 前提MODから流用できるもの

`VehicleProjectileEntity` には、手榴弾に必要な仕組みが既にある。

| 必要な挙動 | 前提MODの仕組み |
|---|---|
| 投げてから一定時間で爆発 | `TimeFuse`(発射からの時間。着弾の有無に関係なく爆発) |
| 地面や壁で跳ねる | `Bound`(跳ね返りの強さ)。着弾で即爆発しないよう、長い `DelayFuse` と組み合わせる |
| 放物線を描いて飛ぶ | `Gravity` |
| 爆発と車両へのダメージ | `Explosion`、`ExplosionBlock` と、車両への爆風ダメージ |
| 投げる物のモデル | `ModelBullet` |
| 破片 | 子弾(`Bomblet`) |

破片手榴弾(フラググレネード)は、ほぼ武器ファイルの設定だけで作れる。

発煙など爆発以外の効果は、前提MODの弾をそのまま使い、弾がワールドから取り除かれたとき(`ServerEntityEvents.ENTITY_UNLOAD`)に発動させる。取り除かれた理由が `DISCARDED` / `KILLED`(信管・着弾)のときだけ発動し、チャンクの読み込み解除では発動しない。

- 当初は `VehicleModelProjectileEntity` を継承した手榴弾エンティティを作る案だった。
- 前提MODの弾の生成は `WeaponProjectileFactory.create` にまとまっており、継承すると生成処理を複製することになるため、この方法にした。

### 種類

| 種類 | 効果 |
|---|---|
| 破片手榴弾 | 爆発と破片 |
| 発煙手榴弾 | 一定時間、煙の雲を出す(下記) |
| 閃光手榴弾 | 爆心を向いていて、視線が通るプレイヤーの画面を白く飛ばす(盲目・吐き気)。範囲内のモブは一時的に狙いを失う |
| 焼夷手榴弾 | 着弾点の周囲を燃やす |
| 信号弾 | 色付きの煙を長く上げる(目印用) |

### 操作(決定)

| 操作 | 内容 |
|---|---|
| 右クリック長押し | ピンを抜く。押している間も信管が進む(クッキング)。長く持ちすぎると手元で爆発する |
| 離す | 投げる |
| 構えキーを押しながら | 下手投げ(近くに転がす。弱く投げる) |

投げた本数だけアイテムが減る。1スタックは最大16個とする。

投げる準備をしている間は、前提MODの爆弾の着弾表示と同じように、軌道と最初の着地点を表示する。

### 発煙の扱い

Minecraft では粒子で視界を完全には遮れない。そこで次の方法を組み合わせる。

- **見た目:** 濃い煙の粒子を範囲内に出し続ける。
- **カメラが雲の中にあるとき:** 霧を濃くして視界を遮る(クライアント側)。
- **モブ:** 雲の中や、雲を挟んだ先のプレイヤーを狙えなくする。
- **ミサイルのロックオン(決定: 煙がロックを吸う):** 前提MODは変更しない。
  - 前提MODのロックオン探索(`WeaponTargeting.findLockOnTarget`)は、照準の方向との内積が最大の候補(生きている `LivingEntity` か車両)を選ぶ。
  - 雲は、周囲のプレイヤーそれぞれの視線上(雲の中)に見えない `LivingEntity` を1体ずつ置き続ける。雲の方向を狙うと、この目標が照準の真正面(内積1.0)になり、ロックは煙に移る。
  - 見えない目標は保存せず、雲が消えると消える。

## 2. 設置型(地雷など)

地雷はブロックではなく、設置面に張り付くエンティティにする。こうすると、半ブロックや斜面、車両の上にも置ける。

### 爆発の方法

起爆時に、その位置で即座に爆発する `VehicleProjectileEntity` を生成する(`TimeFuse = 0`)。こうすると、対戦車地雷が車両に正しくダメージを与える。

### 種類

| 種類 | 起爆条件 | 内容 |
|---|---|---|
| 対人地雷 | 近くを生き物が通る | 小さな爆発と破片 |
| 対戦車地雷 | 車両が上を通る(人は反応しない) | 大きな爆発。車両に大ダメージ |
| 指向性地雷(クレイモア型) | 前方の扇形の範囲に入る | 前方へ破片(弾)を扇状に撃ち出す |
| 遠隔爆薬(C4型) | 起爆装置で起爆 | 車両に貼り付けると車両に追従する。起爆装置と対応付ける |

### 共通の仕組み

- **設置と回収:** 設置後、数秒たってから作動する。設置した本人はしゃがんで右クリックすると回収できる。
- **解除:** 設置者以外が解除するには解除キット(一定時間の作業)を使う。
- **見え方(決定):** 全員に見える。設置者や仲間の区別はせず、誰が近づいても作動する。
- **探知:** 地雷探知機(持っていると近くの地雷を表示する)を関連装備として用意する。

## 3. 関連装備(候補)

| 装備 | 内容 | 実装の見込み |
|---|---|---|
| 双眼鏡・測距儀 | スコープと同じ仕組みで拡大し、見ている地点までの距離を表示する | 既存のスコープの実装を流用でき、容易 |
| 弾薬箱 | 固定ブロック。周囲のプレイヤーの弾倉を補充し、止まっている車両を補給する | **実装済み。** 前提MODの private な補給処理(`receiveAmmoSupply`)を Mixin の `@Invoker` で呼ぶ(enemyvehicleaddon の補給ブロックと同じ方法)。OBJ の補給地点は前提MODの固定設置物で作れる |
| 車両修理キット | 車両の耐久値を回復する | 前提MODの `receiveHealthSupply` を同じ方法で呼べるため、前提MODの変更は不要 |
| 応急手当キット | 使うと一定時間かけて回復する | 容易 |
| レーザー目標指示器 | 地点や目標を指示し、車両の対地ミサイルや航空支援(CAS)の目標にする | 車両の武器側が参照する仕組みを前提MODに追加する必要がある。連携として価値が高い |
| 暗視ゴーグル | ヘルメットに付けると暗視効果 | 防具のアタッチメントとして実装できる |
| ガスマスク | 発煙・催涙の効果を受けない | 防具として実装できる |
| アンダーバレル擲弾発射器 | 銃のアタッチメント。投擲物と同じ弾を撃つ | 銃側の「別の武器ファイルで撃つモード」の追加が必要 |
| パラシュート | — | 前提MODに既にあるため作らない |

## 4. 防具

### アイテム

1種類の防具アイテムに、定義IDと、バニラの装備部品(`minecraft:equippable`)を持たせる。

- 装備する部位と見た目(`equipment` アセット)は部品で指定できる。
- このため、防具の種類を増やすのにコードを変える必要がない。
- 防御力・防具強度・ノックバック耐性は、属性の部品(`attribute_modifiers`)で持たせる。

### 見た目

(決定)最初はバニラと同じ2Dの防具テクスチャ(`equipment` アセット)で作る。あわせて、定義に OBJ モデルを指定できるようにする。

- OBJ を指定した防具は、プレイヤーの描画に追加の描画処理(feature renderer)を足し、頭・胴・脚のモデルの部位に合わせて描く。
- OBJ を指定した場合は、2Dテクスチャの描画を消せるようにする。

### 防御の仕組み

バニラの防御力は、弾にも爆発にも同じように効く。これに加えて、定義で次の軽減率を持たせる。

| 項目 | 対象 |
|---|---|
| `ballistic_protection` | 弾の直撃によるダメージ |
| `blast_protection` | 爆発によるダメージ |
| `headshot_protection`(ヘルメット) | 頭部への命中 |

- **頭部判定:** 弾の命中位置が目の高さ付近なら頭部とし、ダメージを増やす。ヘルメットでその増加分を軽減する。
- **実装:** 被ダメージ量の Mixin で行う。前提MODも乗員へのダメージ倍率で同じ場所を使っており、両方の補正が順に掛かる。
- **耐久値:** 弾を受けると大きく減り、防弾板が割れる扱いにする。

### 候補

- ヘルメット(暗視ゴーグルを付けられる)
- 防弾ベスト(プレートキャリア)
- 重装甲(防弾性能は高いが移動が遅くなる)
- ギリースーツ(遠くのモブに見つかりにくい)
- ガスマスク

## 前提MODへの変更が必要になるもの

1. **ロックオン探索の除外条件:** 不要になった(煙がロックを吸う方法にしたため)。
2. **車両の耐久値を回復する公開メソッド:** 不要になった(`@Invoker` で既存の処理を呼ぶため)。
3. **外部からの目標指示を受け付ける仕組み:** レーザー目標指示器と車両の武器(対地ミサイルやCAS)を本格的に連携させる場合のみ必要。まずは前提MODを変更せず、指示した地点に煙幕と同じ見えない目標を置き、ロックオンを誘導する形で作る。

## 決定事項

| 項目 | 決定 |
|---|---|
| 手榴弾の操作 | 長押しでクッキング、離すと投げる、構えキーで下手投げ。着弾点の表示を付ける |
| 煙幕とロックオン | 前提MODは変更せず、煙がロックを吸う |
| 地雷の見え方 | 全員に見え、誰にでも作動する |
| 防具の見た目 | 2Dテクスチャで始め、OBJ モデルも追加できるようにする |
| 優先順位 | 任せる。弾薬箱は固定ブロックで作る |

## 実装の順序

1. **投擲物と弾薬箱(実装済み・未ビルド):** 破片・発煙・閃光・焼夷・信号、着弾点の表示、弾薬箱。
2. **地雷:** 対人地雷、対戦車地雷、指向性地雷、遠隔爆薬と起爆装置、解除キット、地雷探知機。
3. **防具:** ヘルメット、防弾ベスト、重装甲、ギリースーツ、ガスマスク。弾・爆発・頭部の軽減。OBJ の防具。
4. **関連装備:** 双眼鏡・測距儀、応急手当キット、車両修理キット、暗視ゴーグル、レーザー目標指示器、アンダーバレル擲弾発射器。
